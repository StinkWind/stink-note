# STINK.NOTE 1.0 release page

The public release is branded 1.0. The download is the existing Windows build 1.0.2.

Open `index.html` to preview it locally. All assets are included.

To publish as a standalone GitHub Pages project, put the contents of this folder at the root of the repository, including `.nojekyll`. Under Settings → Pages, select **Deploy from a branch** and choose **main / (root)**.

## // The instrument

| Control | What it does |
| --- | --- |
| **Frequency** | 20–20,000 Hz, including decimals |
| **Waveforms** | Sine, square, sawtooth, triangle |
| **Output** | Live volume control and smooth fades. Press Esc to stop. |
| **Save** | Five-second WAV, 48 kHz, 16-bit mono |
